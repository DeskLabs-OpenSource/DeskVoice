# Fundação do DeskVoice: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** entregar a fundação do DeskVoice: fábrica de contribuição, instalador e um MVP em que uma ligação é atendida por um agente que executa ferramentas, consulta um humano, transfere e deixa tarefas rodando.

**Architecture:** monorepo pnpm com três processos (`apps/panel`, `apps/voice`, `apps/routines`) sobre três pacotes (`packages/core`, `packages/voice-engine`, `packages/tools`). Asterisk fica na borda e entrega áudio por AudioSocket; o banco é Postgres na própria VPS, com um único caminho de schema e fila por LISTEN/NOTIFY.

**Tech Stack:** Node 22, pnpm 9.15.9, TypeScript estrito, Next.js 16 + React 19 + Tailwind 4, `pg`, `ws`, `zod`, Vitest, ESLint, Docker Compose, Postgres 17, Asterisk 20, Caddy 2.

**Spec:** `docs/specs/2026-11-10-fundacao-design.md`

## Global Constraints

- Identificadores de código em inglês; texto de documentação e de tela em pt-BR como origem.
- Nenhum texto visível na tela fora de dicionário (`apps/panel/src/i18n/<locale>/<feature>.ts`).
- Toda tabela tem `organization_id uuid not null` (exceto `organizations` e `schema_migrations`).
- Todo acesso a dados de produto passa por `withOrg(organizationId, fn)`; consulta crua fora de `packages/core` é reprovada por cerca.
- Migration: `db/migrations/<AAAAMMDDTHHMMSS>_<slug>.sql`, só para frente, nunca editada depois de publicada.
- Nenhuma variável de ambiente nova sem valor padrão ou sem ser gerada pelo instalador.
- Teste não usa relógio real, porta fixa nem fuso da máquina: recebe `clock` e porta `0`.
- Sem `any`, sem `@ts-ignore`, sem `catch` vazio.
- Segredo de operador (senha de tronco, chave de IA) é cifrado em repouso com AES-256-GCM (`DESKVOICE_SECRET_KEY`).
- Ligações de saída nascem desligadas (`outbound_policy.enabled = false`).
- Commits em pt-BR no padrão Conventional Commits; nada de push sem pedido do dono.

## Review Focus

1. Motor de voz cai no meio da chamada (WebSocket fecha): a pessoa ouve uma fala de desculpa gravada em texto fixo, a chamada é transferida ou encerrada, e a tela mostra `engine_failed`. Teste em `apps/voice` (Task 6).
2. Chave de IA ausente ou inválida ao atender: a chamada não fica muda; evento `call_refused` com motivo `engine_not_configured` e aviso no painel. Teste em Task 6.
3. Pedido de aprovação sem resposta: expira no prazo e aplica `default_on_timeout`; o agente é informado e segue. Teste em Task 5 e Task 7.
4. Dois processos pegando a mesma tarefa da fila: só um executa (`for update skip locked`). Teste em Task 2.
5. Número de telefone em formato livre ("(31) 99999-8888", "031999998888", "+55 31 99999 8888"): normalizado para E.164 antes de comparar com a lista de não ligar. Teste em Task 2.

### `packages/voice-engine` (`@deskvoice/voice-engine`)

```ts
interface ToolSpec { name: string; description: string; parameters: object }   // JSON Schema
interface VoiceSessionConfig { instructions: string; greeting?: string; voiceId?: string; language: string; tools: ToolSpec[] }
interface VoiceSessionEvents {
  audio(pcm16_8k: Buffer): void
  transcript(turn: { speaker: 'user' | 'agent'; text: string }): void
  toolCall(call: { id: string; name: string; args: unknown }): void
  interrupted(): void
  usage(u: { seconds?: number; inputTokens?: number; outputTokens?: number }): void
  error(e: Error): void
  closed(reason: string): void
}
interface VoiceSession {
  on<K extends keyof VoiceSessionEvents>(event: K, handler: VoiceSessionEvents[K]): void
  sendAudio(pcm16_8k: Buffer): void
  sendToolResult(id: string, result: unknown): void
  say(text: string): void                // pede ao motor uma fala literal
  close(): Promise<void>
}
interface VoiceEngine { id: string; label: string; pricing: EnginePricing; connect(config: VoiceSessionConfig, apiKey: string): Promise<VoiceSession> }
loadEngines(): Promise<Map<string, VoiceEngine>>            // descobre src/engines/*.ts
estimateCostCents(pricing: EnginePricing, usage: Usage): number
resample(pcm16: Buffer, fromHz: number, toHz: number): Buffer
```

Áudio entre a ponte e o motor é sempre PCM16 mono 8 kHz; cada motor converte para o que o provedor pede.

### API do painel (`apps/panel/src/app/api/v1`)

Todas devolvem `{ ok: true, data }` ou `{ ok: false, error: { code, message } }`.

```

GET    /notifications         POST /notifications/:id/read
GET|PUT /settings/:key        GET|PUT /outbound-policy   GET|POST|DELETE /do-not-call

GET    /system/health         GET /system/costs?from=&to=
GET    /events/stream         -- SSE: eventos de chamada da organização
GET    /system/update         -- versão em execução (do processo), agente, último pedido, versões publicadas
POST   /system/update         { password, target }       -- dono ou administrador; só registra o pedido. `target` é a versão
                              -- vista na tela: tem de ser a anunciada pelo agente e ter as notas publicadas
POST   /system/agent          { version, target?, result?, lastFailure? } → { update: boolean }
                              -- `target`: para qual versão o servidor iria. O painel compara com a do pedido e,
                              -- se for outra, encerra o pedido (`superseded`) e responde false
                              -- sem sessão: segredo do instalador em Authorization; recusa pedido vindo por proxy.
                              -- Quem chama é o agente da versão ANTERIOR: campo novo é opcional; a resposta é só o booleano.
```
