## Como foi medido

- Cada item foi medido de novo contra a `main` de hoje. O estado de 11/11 não foi copiado.
- Item de arquivo e de leitura: o arquivo foi aberto nesta medição. A evidência cita caminho e linha.
- Item de comando: o comando rodou nesta medição. Rodaram, todos verdes:
  - `pnpm fences`: 19 arquivos, 41 testes;
  - `pnpm lint`, `pnpm typecheck` e `pnpm test`: 30 arquivos, 342 testes;
  - `bash install/test/run.sh`: 17 arquivos, 1220 verificações, 0 falhas, com o Docker de mentira dos testes do kit;
  - `bash install/install.sh --dry-run --yes` com respostas de exemplo, numa pasta de rascunho.
- Os testes de banco (`pnpm test:db`) não rodaram aqui: o Docker estava desligado e não foi ligado. Para eles a evidência é o teste lido mais o job do CI da `main` em `bfa6d6e`.
- Item de execução: o sistema não foi subido e nenhuma VPS foi acessada. Conta como conforme só o que tem evidência apontável:
  - execuções do CI (`gh run list`, `gh run view`, logs de job);
  - releases publicadas (`gh release list`: `v0.1.0` e `v0.2.0`);
  - registros em [`instalacao-real.md`](instalacao-real.md) e [`nao-exercitado.md`](nao-exercitado.md).
- O que só foi afirmado, sem evidência apontável, ficou **Não medido**, com o que provaria.
- O GitHub foi consultado só para leitura: `gh api`, `gh pr list`, `gh run list`, `gh run view`, `gh release list`. O repositório do site foi clonado numa pasta de rascunho, também só para leitura.
- Itens de nível L que dependem de decisão ainda aberta do dono ficaram marcados pelo estado de hoje, com a decisão citada e sem proposta. Essas decisões são o site em deskvoice.com.br, o domínio do app, o padrão do painel sem domínio e a equipe autônoma de agentes.
